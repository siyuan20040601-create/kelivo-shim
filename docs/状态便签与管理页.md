# 状态便签(look)与只读管理页(/admin/window)

按交接邮件《状态便签与验真页 脱敏复刻教程》实现的两个独立功能。
都是"钥匙即开关":不设对应变量,功能整个不存在。

## 一、状态便签(look)

她在 iPhone 快捷指令里随手写一句近况 → 存进持久卷(只留最新一条)→
他需要时调一次无参数工具 `look` 读取。不主动唤醒、不轮询、不进长期记忆。

**启用**(Zeabur 环境变量):

- `STATUS_WRITE_TOKEN=<自己生成的长随机值>` —— 必须,独立于 SHIM_KEY
- `STATUS_FILE` —— 可选,默认 `/persona/status/now.json`

entrypoint 会在启用时自动把 look 条目写进 `.mcp.json`(/src 与 /persona 两份),
`allowedTools` 自动补 `mcp__look`,无需手工改配置。改完变量 Restart 生效
(有会话恢复,重启不丢窗口)。

**iPhone 快捷指令**:

1. 新建快捷指令 → 添加「询问每次运行时」,类型「文本」;
2. 添加「获取 URL 内容」,URL `https://<shim域名>/status`,方法 POST,请求体 JSON,
   字段 `text` = 上一步的「提供的输入」;
3. 请求头:`Authorization` = `Bearer <STATUS_WRITE_TOKEN>`,
   `Content-Type` = `application/json`;
4. 「获取词典值」取 `ok`;「如果」ok 为真 → 显示「状态已更新」,否则显示 `error`。

**新鲜度**(服务器按 TZ 计算,模型不自己换算):2 小时内当前;2–8 小时标旧;
8–24 小时标过期仍给正文;超过 24 小时只报最后更新时间,不给正文。
无文件(没留便签)与读取故障(存储坏了)是两种不同回答,不会混淆。

**隐私**:接口响应、日志、/debug 都不回显正文(日志只记字数);
look 的 MCP 端点只接受容器内回环地址,公网打不通。

## 二、只读管理页(/admin/window)

手机浏览器打开 `https://<shim域名>/admin/window`,用 SHIM_KEY 登录(POST 表单,
不走 URL 参数)。显示:

- 窗口进度条 + 真实 token 数、离自动压缩还差多少、上限来源
  (CLI 实报的 autocompact 阈值优先;未报告前按 200k 公式线 167000 夹紧,
  残留的 1M 旧配置不会虚高);
- 85% 提醒 / 90% 归档状态(按会话持久化,恢复同一窗口不重复提醒、不重复归档;
  真实 compact_boundary 后重置);
- 本进程压缩次数、最近压缩时间与压缩前 token;
- 未归档缓冲字数、闸门状态、空转 streak、会话恢复状态;
- 最近用户轮次的验真回执:请求模型 vs 上游实际模型是否一致、思考档位与来源、
  是否见到思考链/签名(只记长度)。空轮标 empty-result,不冒充 completed。

**纯只读**:打开/刷新页面绝不给模型发消息、不触发心跳/归档/压缩/重启
(测试里锁死了这一条)。页面无 JavaScript,15 秒 meta 刷新,CSP default-src 'none'。

**登录安全**:timing-safe 比较;会话只存内存,30 分钟滑动过期;
Cookie HttpOnly/Secure/SameSite=Strict/Path 限定;10 分钟内错 5 次锁 429;
Cache-Control no-store 等安全响应头齐全。

**页面与日志均不含聊天正文、思考正文、签名正文。**

## 验收清单

1. 不设 STATUS_WRITE_TOKEN:POST /status 回 503,/mcp/look 不存在,.mcp.json 无 look 条目。
2. 设好后:快捷指令写一条 → 201;在 Kelivo 问他"看一眼我的便签" → 他调 look 读到原文。
3. 写第二条覆盖第一条;错钥匙 401;非文字 400;日志只见字数。
4. /admin/window:错钥匙 401、五次后 429;登录后看到进度条与回执;
   连续刷新页面,/debug 的轮次数不增加(纯只读)。
5. 重启服务:同一窗口恢复后,85%/90% 的已触发标记不复位(不重复提醒)。
